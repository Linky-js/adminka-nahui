# Установка и настройка бэкенда для админки

Этот документ поможет вам установить и настроить бэкенд на Node.js для универсальной админки.

## Требования

- Node.js версии 14 или выше
- npm (обычно поставляется с Node.js)

## Шаги установки

### 1. Перейдите в папку бэкенда

Откройте командную строку или терминал и перейдите в папку `backend`:

```
cd backend
```

### 2. Установите зависимости

Запустите команду для установки необходимых пакетов:

```
npm install
```

Эта команда загрузит и установит все нужные библиотеки (express, cors, uuid).

### 3. Запустите сервер

После установки зависимостей запустите сервер:

```
npm start
```

Сервер запустится на порту 3000 (или на порту, указанном в переменной окружения PORT).

Вы увидите сообщение: `Server running on port 3000`

### 4. Вход в админку

Откройте браузер и перейдите на `http://localhost:5174/` (фронтенд)

Вам будет показана форма входа. Введите:

- Логин: `admin`
- Пароль: `adminadmin`

После успешного входа токен сохранится в куках на 24 часа, и вы будете автоматически перенаправлены в админку. При следующих посещениях вход будет автоматическим.

### 5. Настройка API в админке

В админке перейдите в настройки API и установите:

- API URL: `http://localhost:3000/` (URL бэкенда)
- Оставьте пользователя и auth_key пустыми (они установятся автоматически после логина)

Теперь админка может работать с этим бэкендом для CRUD операций над сущностями, определёнными в `public/entityConfig.json`.

Данные будут храниться в файлах JSON в папке `backend/data/`.

## Структура проекта

- `server.js` - основной файл сервера
- `package.json` - зависимости и скрипты
- `data/` - папка для хранения данных (создаётся автоматически)

## Расширение

- Для добавления аутентификации замените middleware в `server.js`
- Для использования базы данных замените функции чтения/записи данных
- Для добавления новых эндпоинтов добавьте маршруты в `server.js`
